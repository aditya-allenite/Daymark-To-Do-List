# Daymark To-Do List

Daymark is a simple, responsive task list for planning your day. Add tasks, mark them complete, filter by status, and clear completed items. The app saves tasks in your browser using local storage.

## Features

- Add, complete, and delete tasks
- Filter tasks by all, in progress, or completed
- View your completion progress
- Responsive layout for desktop and mobile
- No installation or build step required

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload the files in this folder to the repository's root: `index.html`, `style.css`, and `app.js`. Include this `README.md` too.
3. Open the repository's **Settings** tab, then select **Pages**.
4. In **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then click **Save**.
6. When publishing finishes, copy the site URL shown on the Pages settings screen and share it.

The URL will look like `https://your-username.github.io/repository-name/`.

## Notes about saved tasks

Each visitor's tasks are stored in that visitor's own browser. Tasks do not sync between devices or between different people. Clearing the browser's site data will remove the saved tasks.
